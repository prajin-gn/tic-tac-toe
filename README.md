# Tic Tac Toe 🎮

A clean, responsive browser‑based Tic Tac Toe game built with **HTML, CSS, and Vanilla JavaScript**.

The project focuses on proper game‑state management, smooth UI feedback, and simple but polished player experience — no frameworks, no libraries.



## ✨ Features

* Two‑player local gameplay
* Turn indicator with player names
* Hover preview (ghost move)
* Smooth symbol fade‑in animation
* Winning cells highlight animation
* Tie detection
* Reset anytime safely
* Responsive layout (works on smaller screens)
* Stable logic (no double‑click or fast‑click bugs)



## 🛠️ Built With

* HTML5
* CSS3 (Grid + Flexbox + Animations)
* Vanilla JavaScript (DOM + State Management)

No frameworks. No libraries. No build tools.

## 🚀 How to Run

### Option 1 — Run locally

1. Download or clone the repository
2. Open `index.html` in your browser

No installation required.

### Option 2 — Play online

Visit the GitHub Pages website for this project.



## 🎯 How to Play

1. Enter names for Player X and Player O
2. Press **Play**
3. Click a cell to place your mark
4. First player to align 3 symbols wins
5. Press **Reset** to start again



## 🧪 Edge Cases Handled

* Clicking same cell twice
* Fast repeated clicking
* Reset during gameplay
* Reset after win/tie
* Hover preview on filled cells
